# D2C-weighted candidate corpus for tests/live_suite.py
#
# ~1000 candidate domains, heavily weighted toward direct-to-consumer brands --
# the site shape the audit is most often pointed at, and the one where product
# schema, faceted navigation, JS storefronts, review widgets and consent
# banners all interact.
#
# This is a CANDIDATE list, not a validated one. Brands fold, rebrand and move
# domains constantly, so run tests/probe_corpus.py over it first to keep the
# ones that still answer; the audit suite is expensive per site and should not
# spend its budget on parked domains. Nothing in the suite is fitted to any
# entry here -- the invariants reference no site's content -- so entries can be
# added or dropped freely.
#
# Grouped by segment so the firing-rate table can be read per segment: a check
# that fires on every apparel store and no SaaS site is telling you something
# about the check, not about apparel.
