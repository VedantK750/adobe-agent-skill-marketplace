# Live audit corpus — one URL per line, `# archetype` comments ignored.
#
# These sites are NOT ground truth and no assertion in live_suite.py depends on
# any specific site's content. They are a *diversity sample*: the suite asserts
# invariants that must hold on ANY site, and the corpus exists to make those
# invariants meet as many markup eras, stacks, CMSs and site shapes as possible.
# Nothing here is fitted to; sites can be swapped freely.
#
# Chosen to span the axes that actually break site auditors:
#   markup era        1990s table markup .. 2025 React/Next
#   render model      fully static .. fully client-rendered
#   scale             a 5-page brochure .. a 10M-URL news archive
#   sitemap shape     none / flat / deep partitioned index
#   page-type mix     single-type (docs) .. wide (ecommerce)
