TEST_SITE_URLS:   https://www.duolingo.com/, https://ghost.org/, https://zerodha.com/

LLM_MODEL:        Claude Opus 5 (claude-opus-5, 2026-09)
AGENT_HARNESS:    Claude Code v2.1.283 (VS Code extension, win32-x64)

ENV_SETUP:        python3 -m pip install -r requirements.txt
                  # PYTHON COMMAND: this manifest writes `python3`, which is
                  # correct on macOS/Linux. On Windows use `py -3` instead
                  # (`python3` is not installed there by default). Every
                  # command below works under either name.
                  # Only `requests` and `beautifulsoup4` are required.
                  # lxml / jsonschema are optional; the audit degrades
                  # honestly without them and still passes validation.
                  # No API key, no network service, no browser needed.

TEST_STEPS:
  1. Unzip the Round 3 submission you already hold
     (brand-ai-readiness-audit.zip) and change into it:

     unzip brand-ai-readiness-audit.zip -d brand-ai-readiness-audit
     cd brand-ai-readiness-audit
     python3 -m pip install -r requirements.txt

     That package IS the engine. Nothing else needs to be fetched: the
     marketplace is self-contained, needs no API key and no network service,
     and the manifest resolves without any external lookup.

  2. Open an agent session in that directory (Claude Code) and give it this
     prompt verbatim:

     Read marketplace.json to find the entrypoint skill and follow its SKILL.md. Audit these three sites with --max-pages 10 --no-render, writing each to its own folder: https://www.duolingo.com/ to ./audit-run/duolingo, https://ghost.org/ to ./audit-run/ghost, and https://zerodha.com/ to ./audit-run/zerodha. For each site list the findings in priority order with severity and evidence. Then take the single most severe finding across all three and show its full mechanism, fix steps and verification.

     The agent resolves the entrypoint from marketplace.json, reads the
     entrypoint SKILL.md, and runs the command that skill documents, once per
     site:

     python3 skills/audit-orchestrator/scripts/run_audit.py --url https://www.duolingo.com/ --workdir ./audit-run/duolingo --max-pages 10 --no-render --markdown
     python3 skills/audit-orchestrator/scripts/run_audit.py --url https://ghost.org/ --workdir ./audit-run/ghost --max-pages 10 --no-render --markdown
     python3 skills/audit-orchestrator/scripts/run_audit.py --url https://zerodha.com/ --workdir ./audit-run/zerodha --max-pages 10 --no-render --markdown

  3. Each run writes audit-report.json (schema-validated) and audit-report.md
     (human-readable) into its own folder. Findings are sorted by severity,
     then by ascending effort, so the top of each list is the prioritized fix
     order. Per-skill evidence fragments are written to fragments/ and the raw
     crawl evidence to snapshot.json, so every finding traces back to what was
     actually fetched.

EXPECTED_OUTPUT:  ./audit-run/duolingo/audit-report.json
                  ./audit-run/ghost/audit-report.json
                  ./audit-run/zerodha/audit-report.json
